# Магазин товаров (Product System)

## Описание
Проект реализует систему для управления товарами различных типов (например, смартфоны и газонная трава), используя ООП-принципы Python. Он демонстрирует наследование, переопределение магических методов, работу с типами и тестирование.

## Структура
- `Product` — базовый класс для товаров
- `Smartphone` — наследник `Product`, включает характеристики смартфона
- `LawnGrass` — наследник `Product`, включает характеристики газонной травы
- `Category` — представляет категории товаров с проверкой типов и учётом количества
- `main.py` — демонстрация работы всех классов
- `tests/` — тесты на основе pytest с покрытием >75%

## Установка и запуск
```bash
python main.py
```

## Запуск тестов
```bash
pytest --cov=src tests/
```

## Реализованные требования
- Проверка типов в методах сложения и добавления
- Магические методы `__add__`, `__str__`
- Защита от ошибок типа
- Покрытие тестами > 75%
